# cast-consistency

**Trigger:** load when the user says "she looks different", "face
drift", "who is that", "keep the same actor", or when `_board.png` tiles
show the same character with different faces/outfits.

## Why this exists

Visual discontinuity is the #1 dropout driver — one (directional,
single-source) measurement puts it at 92% of drop-offs. Character
identity does NOT live in shot prompts; it lives in the series bible:
`series.CAST[i].look` (the canonical text description) plus
`ref_images` (4-6 references per character: a four-view sheet — 1/4
head close-up + front/side/back full body on white — plus 1-2
expression refs). Assets follow the naming convention `人名_特征`
(name_feature), e.g. `林野_6岁`. The `cast-book` skill owns creating and
updating all of this.

Within an episode, consistency also means the SAME cast id every time
the character appears — the validator rejects unknown ids, but it can't
catch a second id accidentally minted for the same person.

## Use the helper

```python
from dramalib.bible import Character  # the shape series.CAST entries take
```

The flow: (1) keep every character's `look` specific and stable in
`series.py` — costume, age, hair, one signature detail; (2) run the
`cast-book` skill to generate reference prompts / images into
`cast/<id>/` and update the marked CAST block; (3) in shot prompts,
refer to the character by ROLE + cast id context ("she", "the bride"),
never by re-describing their appearance — re-description fights the
refs.

## Pitfalls

- **Describing appearance in shot prompts**: "a woman with a black bob
  in a gray suit" invites the model to recast her per shot. Appearance
  lives in `look` + refs only.
- **Editing `series.py` casually**: the bible is folded into every
  episode's fingerprint — a cast tweak invalidates and re-renders ALL
  episodes. Batch cast changes; do them before a render pass.
- **Hand-editing the marked CAST block**: the `# CAST-BOOK BEGIN/END`
  block is regenerated by the cast-book skill; hand edits inside it get
  overwritten. Edit via the skill.
- **Costume changes mid-scene**: a costume is part of identity; if the
  story needs a change, make it a new scene and say so in the location
  line.
- **More than 3 leads**: every additional consistent face multiplies
  drift risk and ref workload. 2-3 leads (`LEADS_PER_SERIES`); everyone
  else stays background.
