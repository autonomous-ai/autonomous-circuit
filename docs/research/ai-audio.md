# ai-audio

AUDIO / VOICE / MUSIC / SOUND — STATE OF THE ART (Aug 2026) and what to steal for Autonomous TV

Context: I read the live engine (`/Users/d/code/autonomous-tv/packages/dramapy/src/dramapy/{voices,audio,sfx,postprocess}.py`) and the `dramacode/references/sound-design.md` craft doc first, so these findings target REAL gaps, not things already built. The engine already does: ElevenLabs eleven-v3 TTS with pinned voices + per-line emotion tag + stability; ElevenLabs Music with a native sectioned `composition_plan` (Lyria2 fallback); ElevenLabs SFX + mmaudio-v2 foley; sync-lipsync/v2 lip-sync; Topaz upscale; sidechain ducking of score under dialogue. It is genuinely strong. The frontier moves are below.

=== CURRENT MODEL LANDSCAPE (verified, with fal prices where the engine buys them) ===

VOICE (TTS)
- ElevenLabs eleven-v3 — the expressive frontier: 70+ languages, audio tags for emotion/non-verbals/delivery ([whispers],[laughs],[sighs],[sarcastic],[crying]…) and some SFX tags, native MULTI-SPEAKER dialogue, and three stability modes (Creative = expressive/prone to hallucination · Natural = balanced · Robust = stable but ignores direction). 5,000-char limit. On fal ~$0.10/1k chars. Docs: https://elevenlabs.io/docs/capabilities/text-to-speech and v3 tag guide https://elevenlabs.io/docs/best-practices/prompting/eleven-v3
- ElevenLabs Text-to-Dialogue API — NEW and directly relevant: renders a whole multi-speaker exchange in ONE call on eleven-v3, with real turn-taking; interruptions/trailing-off are driven by punctuation; unlimited speakers; 2,000 chars/request; seed for repeatability. https://elevenlabs.io/docs/capabilities/text-to-dialogue
- ElevenLabs Voice Design v3 — design a bespoke voice from a text persona prompt (Native [lang]; gender/age; persona; emotion; timbre/pacing), guidance-scale control, saveable/pinnable. Still "experimental"; Professional Voice Clones are more stable but not yet on v3. https://elevenlabs.io/docs/product-guides/voices/voice-design
- Rival: MiniMax Speech-02-HD on fal — 30+ langs, 300+ preset voices, emotion/speed/pitch, $0.10/1k chars. Solid multilingual fallback / non-English casting. https://fal.ai/models/fal-ai/minimax/speech-02-hd

MUSIC / SCORE
- ElevenLabs Music v2 — studio-grade, commercial-cleared (film/TV/ads/games), 3s–5min, section-by-section composition, MID-TRACK GENRE TRANSITIONS, and INPAINTING (regenerate one section without touching the rest), plus stems. API for paid tiers. On fal $0.8/output-minute (billed rounded up). https://elevenlabs.io/docs/capabilities/music and https://fal.ai/models/fal-ai/elevenlabs/music
- Google Lyria 3.5 — up to 3-min tracks, image-to-music, vocal-style control; access via Vertex/Gemini/AI Studio; SynthID-watermarked. Good instrumental fallback. https://deepmind.google/models/lyria/
- Suno v5.5 — best consumer quality, 12 time-aligned WAV stems, but commercial rights are tied to a paid subscriber owning the song and there is NO clean redistribution/API license for a platform reselling output. VERDICT: keep ElevenLabs Music primary (commercial-cleared + composition/inpainting API), Lyria fallback; do NOT build on Suno for a product we sell. https://suno.com/

SOUND / FOLEY
- mmaudio-v2 (video-to-audio) — analyzes frames, returns temporally-aligned audio; 1–30s; $0.001/s (dirt cheap). https://fal.ai/models/fal-ai/mmaudio-v2
- RISK: the engine's DEFAULT discrete-SFX endpoint `fal-ai/elevenlabs/sound-effects` is now DEPRECATED on fal ("This model is no longer supported"). It still lists $0.002/s but is not a safe production default. Must move discrete stingers off it. https://fal.ai/models/fal-ai/elevenlabs/sound-effects

LIP-SYNC / TALKING PERFORMANCE (the biggest quality lever for "Oscar-level")
- sync.so — current line is Sync-3 ("most intelligent lipsyncing"), lipsync-2-pro (occlusion handling, multiple faces, 4K ProRes, active-speaker detection, low-light, fast camera), and React-1 (reaction/listening model). https://sync.so/ . On fal: sync-lipsync/v2 = $3/min; sync-lipsync/v2/pro = $5/min (preserves teeth/facial detail, occlusion, multi-face, 4K, active-speaker) https://fal.ai/models/fal-ai/sync-lipsync/v2 — engine uses the $3 standard tier only.
- ByteDance OmniHuman on fal — image + audio → full talking-head performance (not just mouth: audio-driven head/expression), up to 30s, $0.14/s. Trained on ~18,700h of motion. https://fal.ai/models/fal-ai/bytedance/omnihuman
- Hedra (Character-3 / Omnia / "Hedra Avatar") — audio+image expressive character video. https://www.hedra.com/models
- Runway Act-Two — performance TRANSFER (face + body + hand gestures + environmental motion) from a driving performance onto a character; best when you have a real acting reference. (Runway research page 403s to bots; capability confirmed via product listings.)
- NATIVE-AUDIO VIDEO alternative: Veo 3.1 on fal generates synced dialogue+SFX+ambient+music WITH lip-sync in one pass, 720p/1080p/4K, 8s extendable ~148s, $0.40/s at 1080p audio-on ($0.15 on Fast). SynthID-watermarked. Tradeoff: you lose per-character voice-identity control (why the engine deliberately strips clip audio). Use for spectacle/ambient, not hero dialogue. https://fal.ai/models/fal-ai/veo3.1

KEY GAPS vs the engine (what the steals below fix): (1) discrete-SFX default points at a dead endpoint; (2) lip-sync is single-tier — close-ups get the same $3 model as wide shots; (3) dialogue is concatenated isolated lines, not co-modeled turn-taking (Text-to-Dialogue unused); (4) casting is limited to eleven-v3's default library pool (Voice Design unused); (5) no audio-driven facial PERFORMANCE — only mouth-repaint on an existing clip; (6) score section boundaries are fixed fractions (0.15/0.60/0.88), not the real gut-punch timestamp; (7) no section-inpainting reroll; (8) no final loudness normalization; (9) reaction/listener shots are dead (no React-1).

## Steals
- [S] Retire the deprecated SFX default endpoint (fal-ai/elevenlabs/sound-effects is 'no longer supported' on fal). Make mmaudio-v2 the default for motion/impact shots and route discrete stingers to a live SFX source (ElevenLabs SFX via their own API, or keep a verified fal endpoint); add a smoke check that fails loudly if the SFX endpoint 404s. — The engine's current default discrete-SFX path can silently die in production; SFX is the single strongest measured completion lever (+172% on slap+glass-shatter per the sound-design doc). Also mmaudio is $0.001/s vs $0.002/s and motion-matched. (https://fal.ai/models/fal-ai/elevenlabs/sound-effects)
- [S] Tier the lip-sync: route close-ups / gut-punch / emotional shots to sync-lipsync/v2/pro ($5/min: occlusion handling, teeth/detail preservation, active-speaker, 4K), keep the $3 standard for wide/low-stakes shots. — Lip precision is only visible in close-up — exactly the shots that carry the emotion. Paying $5/min on the ~20% of shots that are hero close-ups is a large perceived-quality gain for a tiny cost delta. (https://fal.ai/models/fal-ai/sync-lipsync/v2/pro)
- [M] Adopt ElevenLabs Text-to-Dialogue (eleven-v3) for two-hander scenes: render a scene's back-and-forth as ONE dialogue call (multi-speaker, turn-taking, punctuation-driven interruptions/overlaps) instead of synthesizing and concatenating isolated lines. — Concatenated solo lines never breathe together — timing, interruptions and reactive delivery are what make a scene feel acted. Co-modeling the exchange is the difference between a table-read and a performance. 2,000 chars/request fits a drama scene. (https://elevenlabs.io/docs/capabilities/text-to-dialogue)
- [M] Cast bespoke voices with Voice Design v3 from each Character's persona text in the cast bible (Native lang; gender/age; persona; emotion; timbre), pin the resulting voice id per character, fall back to the default library pool if a design is unstable. — Casting is currently limited to eleven-v3's default library, so distinct characters can collide and a series' voices aren't authored. Designed voices give each character a signature and scale past the preset pool — series-consistency + distinctiveness. (https://elevenlabs.io/docs/product-guides/voices/voice-design)
- [L] Add an audio-driven PERFORMANCE path for hero dialogue close-ups: generate the shot from the character reference image + the ElevenLabs line via ByteDance OmniHuman ($0.14/s) or Hedra, so brows/gaze/head-motion act WITH the voice — instead of Kling i2v then mouth-only repaint. Keep Kling+lipsync for non-dialogue and wide shots. — sync lip-sync only repaints the mouth on footage the actor never 'performed' — dead eyes on the emotional beats. Audio-to-performance models drive the whole face from the voice, which is where Oscar-level acting lives. (https://fal.ai/models/fal-ai/bytedance/omnihuman)
- [M] Make the score arc beat-accurate: drive the ElevenLabs composition_plan section boundaries from the ACTUAL stitched shot offsets (especially the gut-punch shot's real start time) instead of the fixed 0.15/0.60/0.88 fractions, so 'cut the score at the gut-punch' lands on the frame. — The craft doc's marquee move is dropping music exactly at the heartbreak; a fractional guess misses it by seconds. The engine already computes per-shot timeline offsets, so this is wiring existing data into composition_plan. (https://elevenlabs.io/docs/capabilities/music)
- [M] Add a music section-inpainting reroll: when the climax or hook section is weak, regenerate ONLY that ElevenLabs Music section (inpainting / mid-track edit) rather than the whole bed. — Cheaper, faster iteration and it preserves the parts that already work — the reroll loop the platform will lean on constantly. Whole-bed regeneration currently throws away good sections and re-rolls the whole $0.8/min cost. (https://elevenlabs.io/docs/capabilities/music)
- [S] Add a final-mix EBU R128 loudness normalization (two-pass ffmpeg loudnorm to ~-14 LUFS for vertical social) on the muxed episode. — Per-episode loudness currently drifts; a series that jumps in perceived volume reads as amateur and gets muted. One cheap two-pass filter makes the whole catalog sit at platform-standard loudness. (https://elevenlabs.io/docs/capabilities/text-to-speech)
- [S] Use non-verbal eleven-v3 performance beats from the shot emotion: inject a [sharp inhale]/held breath before the reveal, [sighs], [voice breaking] on loss/tender beats (mid-line tags allowed), and pair with the score dropping out. — The sound-design doc explicitly wants 'a held breath carries the heartbreak' — v3 supports exactly these non-verbal tags. This is the audible half of the gut-punch the engine currently leaves silent. (https://elevenlabs.io/docs/best-practices/prompting/eleven-v3)
- [M] Animate the LISTENER in two-handers with sync React-1 (or a lipsync pass on a silence track), so reaction cutaways to the non-speaking character show genuine reactive micro-motion instead of a frozen face. — Drama is reaction shots. Right now only the speaker's mouth moves; cutaways to the listener are dead frames, which telegraphs 'AI'. React-1 is purpose-built for this. (https://sync.so/)
- [L] Add a Veo 3.1 native-audio premium tier for spectacle/ambient shots (explosions, crowds, weather, establishing) where lip-identity doesn't matter: one call yields synced SFX+ambient, skipping the separate mmaudio+SFX+mix passes on those shots. A/B vs the composed pipeline. — For non-dialogue spectacle, native-audio video is more coherent (sound generated from the exact pixels) and can be cheaper per shot than i2v + foley + mix. Reserve it for shots where per-character voice control is irrelevant. (https://fal.ai/models/fal-ai/veo3.1)
- [S] Extend mmaudio motion-matched foley from just action/establish shots to ANY shot with an on-screen physical event (a set-down cup, a closing door, footsteps in dialogue), layered UNDER the discrete stinger. — At $0.001/s it's nearly free, and the connective-tissue shots are where silence currently reads as flat. Motion-matched ambience fills the floor without going to SFX mush. (https://fal.ai/models/fal-ai/mmaudio-v2)
