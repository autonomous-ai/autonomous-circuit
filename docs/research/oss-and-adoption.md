=== DOMAIN A: OPEN SOURCE TO STEAL (beyond MoneyPrinterTurbo/ComfyUI/VideoClaw/Toonflow) ===

THE ONE TO STUDY LINE-BY-LINE — wind-comic (445★, MIT) https://github.com/ChrisChen667788/wind-comic
This is us, shipped by someone else. "One sentence in. A finished short-form drama out — script, cast, storyboards, voiceover, timeline, mp4." It is an explicit 8-agent pipeline (Writer, Director, Producer, Character Designer, Storyboard Artist, Cameo Locker, Lipsync, Editor) with, quote, "strict consistency contracts" on every handoff. Concrete mechanisms worth lifting: (1) vision-audited storyboards (a model checks the rendered board matches the prompt before video spend); (2) multi-engine video "race" (render a shot on several engines, keep the best); (3) a lip-sync pipeline described as "viseme track → align score → drift auto-correct → engine render → back into timeline" — this is exactly the ceiling task #19; (4) an Editor that does j-cut/l-cut + BGM-per-act + CJK subtitles; (5) real-time multiplayer timeline via Yjs CRDT ("Figma for film"); (6) a template market — save a hit project, rate/favorite/one-click remix WITH its voices; (7) per-project cost attribution + budget guard + a "four-dimension publish gate." MIT-licensed, so the code and the architecture are both fair game.

CHARACTER CONSISTENCY
- StoryDiffusion (6447★, Apache-2.0, NeurIPS'24 spotlight) https://github.com/HVision-NKU/StoryDiffusion — "Consistent Self-Attention," hot-pluggable into any SD1.5/SDXL model, needs 3-6 prompts to lock a character across a sequence; plus a motion predictor for long-range video. ComfyUI port exists: smthemex/ComfyUI_StoryDiffusion (512★). This is a real fallback lever when fal-hosted reference conditioning drifts.
- ComfyUI_VNCCS — Visual Novel Character Creation Suite (1517★, MIT) https://github.com/AHEKOT/ComfyUI_VNCCS — generates consistent character sprite sheets (multi-pose/expression). Directly maps to the cast-book skill's per-character reference slots.
- fofr/cog-consistent-character (722★, MIT) https://github.com/fofr/cog-consistent-character — one image → same character in many poses. Cheap way to fill reference sheets.

TIMELINE / EDITING INFRASTRUCTURE
- OpenTimelineIO (1951★, Apache-2.0, Academy Software Foundation) https://github.com/AcademySoftwareFoundation/OpenTimelineIO — the industry-standard editorial timeline interchange. Adopting it as our internal timeline model gives free import/export to Premiere, Resolve, FCP — the escape hatch that makes real producers trust us (they can finish in their NLE). Has a viewer (OTIO/raven) too.
- autoclip (53★, MIT) https://github.com/artbyjazi/autoclip — local-first, ships the WHOLE loop "ingest → clips → review → export": Whisper transcription, LLM highlight selection, MediaPipe speaker-tracked vertical reframing, and libass-burned animated captions in FOUR styles, at three aspect ratios. Notes the ffmpeg gotcha (needs a full build with libass + libx264). Clean, small, MIT — the caption + reframe modules are liftable.
- NarratoAI (10634★, MIT) https://github.com/linyqh/NarratoAI — one-click AI narration + auto-edit; recent releases added IndexTTS-1.5 MLX (Apple-Silicon local TTS voice clone), optional AI scoring, and a documentary frame-extraction→vision→script chain. Big traction in the Chinese short-video world.
- MoviePy (14834★, MIT) https://github.com/Zulko/moviepy is the default; movielite (67★, MIT, Numba-accelerated) https://github.com/francozanardi/movielite is a faster drop-in worth benchmarking for local compositing.

STORY / STORYBOARD / SCREENPLAY AGENTS
- Seedance2-Storyboard-Generator (2051★, NO LICENSE — can't copy code, can copy the scheme) https://github.com/liangdabiao/Seedance2-Storyboard-Generator — notable because it is already packaged as a Claude Code Skill (.claude/skills/seedance-storyboard-generator). Its asset-bible scheme is the steal: numbered, typed reference assets — C01–C99 characters (multi-angle), S01–S99 scenes, P01–P99 props — plus a four-act 起承转合 structure and a Seedance-timeline prompt format, with per-episode video-extension for seamless episode-to-episode continuity.
- scriptbreak (41★, Apache-2.0) https://github.com/wassermanproductions/scriptbreak — local, no-cloud screenplay breakdown → scenes, characters, locations, props, shot lists, timeline; exports "prompt packs that turn any LLM into your assistant director." Part of a whole filmmaker suite (Blockout, Motion Previs Studio, DaVinci MCP) worth watching. Good breakdown data model to mirror.
- Additional blueprints: story-flicks (2452★, alecm20) one-click story shorts; AIComicBuilder (1758★, Apache-2.0); Film-Production-Toolkit (slipknot0130) multi-agent "影视工业化" workbench with a 编剧室 (writers'-room) SOP + storyboard-prompt engine over 12+ LLM providers; ai-screenplay-writer (E-Asrar-Haghighi, MIT) LangGraph writers'-room that writes full seasons; HoLLMwood (screenwriting-via-role-playing paper).

AGENT CONTROL PLANE
- comfyui-mcp (528★, MIT) https://github.com/artokun/comfyui-mcp — the pattern to copy for adoption: an MCP server (37 tools) + sidebar agent that drives ComfyUI in natural language, ships model-specific "expert skills" (curated sampler/CFG/resolution/model-URL recipes so the agent gets each architecture right without trial-and-error), works with BYO subscription/local/hosted LLM, and — critically — "asks before spending paid API credits." === DOMAIN B: THE "CLAUDE CODE OF X" ADOPTION PATTERN ===
Source for all of this: Anthropic's own Claude Code best-practices (redirected to) https://code.claude.com/docs/en/best-practices

Why coders adopted Claude Code / Cursor so hard, distilled to the drivers — and what each demands of a producer-facing film tool:

1) THE VERIFIABLE AGENTIC LOOP. The doc's #1 principle: "Give Claude a check it can run... the loop closes on its own. Claude does the work, runs the check, reads the result, and iterates until the check passes." The whole magic is a self-closing loop, not a chatbot. FILM TRANSLATION: our crew must have its own pass/fail checks it runs WITHOUT the producer — a storyboard vision-audit (does the frame match the prompt?), a character-consistency score, a lip-sync-drift check, an audio-loudness gate — and auto-iterate until they pass. wind-comic already proves this works ("vision-audited storyboards," "four-dimension publish gate").

2) EXPLORE → PLAN → APPROVE → THEN SPEND. "Letting Claude jump straight to coding can produce code that solves the wrong problem. Use plan mode." Plans are editable (Ctrl+G opens the plan in your editor) before execution. FILM TRANSLATION — this is the single biggest one for a paid pipeline: never spend video-gen dollars before the producer approves a plan. Show script + shot list + storyboard STILLS (cheap) + a per-shot cost estimate, let them edit it, then render. Approval gates the expensive step.

3) TRANSPARENCY — EVIDENCE, NOT ASSERTION. "Have Claude show evidence rather than asserting success." FILM TRANSLATION: expose every intermediate artifact and WHICH model made it and what it cost — the board, each shot render, the model-per-shot, the cost-per-shot. Never a spinner that says "making your film."

4) TIGHT, CHEAP FEEDBACK + COURSE-CORRECT + REVERSIBILITY. Esc to redirect, "undo that," /rewind checkpoints ("Every prompt creates a checkpoint... restore conversation, code, or both"). FILM TRANSLATION: per-shot reroll and targeted edits ("make her angrier in the confession scene" — dramacode already does this), plus timeline checkpoints so any shot/version is restorable, and a fast low-res/2D-lip-bar PROXY loop so producers iterate free before committing to the expensive final render.

5) PERMISSION GRADIENT = COST GOVERNANCE. Default ask → allowlist safe tools → "auto mode" (a classifier lets routine work run, blocks risky) → sandbox. FILM TRANSLATION: ask before any paid spend, auto-allow the free/cheap ops (stills, TTS, layout), offer an "auto mode" that runs to a budget cap, and a hard budget guard that stops. (comfyui-mcp and wind-comic both independently arrived at "ask before spending credits.")

6) PERSISTENT PROJECT MEMORY (CLAUDE.md). "A special file Claude reads at the start of every conversation... keep it short... check it into git... compounds in value." Rule: only include what would cause mistakes if removed. FILM TRANSLATION: the series bible is our CLAUDE.md — cast, style, voice, canon, banned looks — short, editable, loaded on every render. series.py is already this; make it explicitly the always-loaded contract.

7) EXTENSIBILITY = STICKINESS (skills, MCP, hooks, subagents, plugins, BYO). Coders stayed because they could bend it: custom skills, MCP servers, hooks that "guarantee the action happens," and a plugin marketplace. FILM TRANSLATION: let producers add their own crew members (a custom "colorist" or "voice-director" agent), bring their own LLM + engine keys (wind-comic: "3 env vars, 0 code change"), define hooks (auto-run the consistency check after every render), and share/remix templates in a market.

8) ADVERSARIAL REVIEW IN A FRESH CONTEXT. "A reviewer running in a fresh subagent context sees only the diff and the criteria... evaluates the result on its own terms," and "flag only gaps that affect correctness... not style." FILM TRANSLATION: a continuity/critic agent that reviews the finished cut against the brief in a clean context — reports real drift (wrong face, broken eyeline, dead audio), not taste notes.

9) INTERVIEW-ME INTAKE → SPEC. For big features: "have Claude interview you first... using the AskUserQuestion tool... then write a complete spec." FILM TRANSLATION: the story-analysis skill already does this — a structured interview that turns "make me a revenge drama" into a production brief. Keep and harden it; it is the on-ramp.

10) FAN-OUT / NON-INTERACTIVE SCALE. `claude -p` in loops, parallel sessions, worktrees. FILM TRANSLATION: batch-render a 60-episode season non-interactively, parallelize shots, and run the multi-engine race — the throughput story a studio buys.

BOTTOM LINE: the coders' loyalty came from a loop that (a) plans before it acts, (b) checks its own work, (c) shows its work, (d) is cheap to correct and impossible to lose, and (e) bends to the user's tools and budget. A producer will adopt us for the same five properties, with "check its own work" = automated film-QA gates and "plan before it acts" = approve-before-spend. wind-comic is the proof these translate cleanly to film; Claude Code's doc is the spec for HOW to make them feel trustworthy.
